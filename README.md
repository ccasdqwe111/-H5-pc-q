# 知识付费系统源码 支持H5、小程序和pc端分站分销多种变现模式

源码获取：ym7k.com/19803/

当下知识付费赛道持续发展，讲师、工作室、培训机构、自媒体团队想要搭建自有知识平台，往往会遇到多端割裂、变现方式单一、学员沉淀难、推广激励不足、多区域代理运营不好落地等问题。市面上很多轻量工具要么只能做小程序、缺少 PC 管理和访问端，要么不支持分站代理，分销机制简陋，很难满足规模化运营需求。这套基于 FastAdmin+ThinkPHP+UniApp 开发的知识付费系统源码，**一套源码同时支持微信小程序、H5、PC 端**，内置分站代理、多级分销、内容售卖等多种变现模式，私有化部署、支持二次开发，适合讲师个人、教育工作室、行业社群、培训机构搭建独立品牌知识付费平台。

## 技术架构说明

后端基于 FastAdmin 开发，依托 ThinkPHP 框架，复用成熟的 RBAC 权限体系、插件扩展、API 管理、CRUD 快速开发能力，后台稳定易维护，方便开发者自定义功能。移动端采用 UniApp 开发，一套源码编译微信小程序与 H5；独立 PC 端前台可供学员访问学习，同时 PC 后台用于管理员、分站、讲师管理。
环境兼容主流 LNMP 架构，支持独立私有化部署，所有课程数据、订单、用户信息自主存储，不依赖第三方 SaaS 平台，没有平台抽成。系统接口分层清晰，可按需拓展，支持对接微信支付、支付宝，配置短信、消息模板通知。平台角色权限隔离：总平台管理员、分站管理员、入驻讲师、普通学员权限分开，保障分站独立运营互不干扰。

## 核心功能模块

### 1. 多形态知识内容管理

平台支持多种知识商品类型，适配不同交付形式：视频课程、音频专栏、图文专栏、PDF 文档、直播课程、系列合集、训练营、付费社群、付费问答。
课程支持设置免费试看、部分章节试听，支持按单集售卖、整套专栏售卖；可设置限时折扣、定时上架、课程有效期。学员在小程序、H5、PC 端三端学习进度自动同步，观看记录、学习时长、收藏记录跨端互通。配套课程评价、学习笔记、问答评论，提升内容互动性。讲师可自主上传课程、管理订单、查看收益，平台可设置讲师分成比例。

### 2. 丰富的变现模式

- **直接售卖**：单课程、专栏、资料包单独付费购买；
- **会员套餐**：月卡、季卡、年卡、终身会员，开通会员后全站或指定分类课程免费学；
- **卡密兑换**：生成课程卡密、会员卡密，线下引流、活动赠送、渠道批量发放；
- **付费问答**：学员付费向讲师提问，讲师接单回复；
- **付费社群**：付费解锁微信群 / 专属圈子，沉淀私域学员；
多种变现方式自由组合，运营者可以根据业务灵活搭配。

### 3. 分站代理体系（区域分站）

分站是这套系统的一大亮点。总后台可以开通多个分站，每个分站拥有独立后台、独立推广链接、独立域名（H5/PC），分站可以自主设置分站名称、首页装修、上架课程（可同步主站课程或自主上架）。
分站拥有自己的推广收益、订单统计，总平台统一管控分成比例、权限开关。适合按城市、行业渠道发展代理，渠道商负责本地引流获客，无需开发系统，依托主站内容做本地化知识服务，帮助平台快速拓宽获客渠道。分站订单收益自动结算，后台可查看分站业绩、导出对账报表。

### 4. 分销推广裂变体系

内置分销机制，支持自定义分销层级，学员、讲师、分站都可以成为推广员。每一个课程、会员都生成专属推广海报与链接，分享给好友，好友通过链接下单后，推广人自动获得佣金。
后台可单独设置每个商品的分销比例，支持一级分销、二级分销开关控制；佣金支持实时查看、申请提现，后台审核打款。分销记录、推广订单、佣金明细全程留痕。利用分销激励学员自发分享，低成本实现用户裂变增长。

### 5. 订单、财务与数据统计

所有购买、会员充值、卡密消费、分销佣金、分站收益统一进入财务台账。支持订单退款管理、提现审核、资金流水查询。数据看板可视化展示课程销量、会员增长、成交趋势、分站业绩、分销排行等图表，支持按时间、商品、分站、推广员筛选，报表一键导出 Excel，方便财务对账与运营复盘。
同时配套营销工具：优惠券、限时秒杀、拼团、砍价，用来做引流活动，提升转化。

### 6. 首页可视化装修与用户运营

小程序、H5、PC 前台都支持可视化首页拖拽装修，轮播图、课程分类、推荐专栏、会员入口、讲师展示模块自由排版，快速打造符合品牌风格的页面。支持微信授权登录、手机号登录，用户中心集中展示我的课程、订单、收藏、学习记录、推广中心、佣金钱包。微信模板消息、短信通知可配置，下单提醒、课程更新、佣金到账、提现审核结果自动推送。

## 适用人群与场景

1. 独立讲师、知识博主：搭建自己的付费课程平台，摆脱第三方平台流量与抽成限制；
2. 培训机构、职业教育团队：售卖技能课程、考证专栏、培训资料；
3. 行业协会、社群：搭建行业知识库，会员付费解锁行业资料、内部课程；
4. 渠道招商团队：依靠分站代理模式发展各地渠道，结合分销做裂变引流；
5. 企业内训平台：搭建内部培训库，同时开放对外知识付费变现。
